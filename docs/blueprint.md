# **App Name**: PsiWell

## Core Features:

- Online Session Booking: Allow users to book sessions directly through the website. Includes options for selecting time slots and specifying session preferences.
- Contact Form Submission: Enable potential clients to submit inquiries via a contact form.
- Multilingual Support: The site should support Portuguese and English. An AI tool automatically detects user language or provides the option to switch languages to cater to both Brazilian and international clients.
- SEO Optimization: Implement structured data (JSON-LD) to enhance search engine visibility, based on schema.org vocabulary.

## Style Guidelines:

- Primary color: Deep blue (#003366) to convey trust and professionalism, reflecting the field of psychology.
- Background color: Light gray (#F2F2F2) to provide a neutral and calming backdrop.
- Accent color: Soft teal (#66CDAA) used for interactive elements and calls to action, offering a sense of tranquility and approachability.
- Body text: 'Inter', a sans-serif font, to ensure readability and a modern feel for all website text.
- Headline font: 'Playfair', a serif font, adds elegance and a touch of formality, suitable for headings and titles. If longer text is anticipated, use 'PT Sans' for body text.
- Use clean, minimalist icons to represent services and support content. All icons should maintain a consistent style and enhance the user interface.
- The layout should be clean and intuitive, with clear sections for About, Services, and Contact. Use white space effectively to avoid a cluttered appearance.
